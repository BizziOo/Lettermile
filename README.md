# Lettermile

Lettermile is a word game in English and Polish. Pass one phone between teams, play on separate phones over the same Wi-Fi network, or solve a Daily puzzle on your own.

## Download the Android beta

[Download Lettermile 0.15.0](https://github.com/BizziOo/Lettermile/releases/tag/v0.15.0) from GitHub Releases. Under **Assets**, choose `lettermile-android-0.15.0.apk` and open it on your Android phone. Android may ask you to allow installation from the app that opens the APK.

For Obtainium updates, add `https://github.com/BizziOo/Lettermile` and enable prereleases.

## Play over Wi-Fi

Connect the phones to the same Wi-Fi network and use the same Lettermile version on each phone. Open **Over Wi-Fi** to create a room. To share an ordinary room nearby, select **Make room visible**. Guests can use its six-character code or **Nearby rooms** and compare the confirmation number with the host. Guests can also join with the QR code or full invitation.
