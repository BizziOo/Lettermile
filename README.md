# Lettermile

Lettermile is a word game in English and Polish. Pass one phone between teams, play on separate phones over the same Wi-Fi network, or solve a Daily puzzle on your own.

## Download the Android test build

[Download Lettermile 0.9.2](https://github.com/BizziOo/Lettermile/releases/tag/v0.9.2) from GitHub Releases. Under **Assets**, choose `lettermile-android-0.9.2.apk` and open it on your Android phone. Android may ask you to allow installation from the app that opens the APK.

To get updates with Obtainium, add `https://github.com/BizziOo/Lettermile` and enable prereleases for Lettermile.

For Wi-Fi games, connect the phones to the same network and use the same Lettermile version on each phone. Open **Over Wi-Fi** on the host to create a room, then use its invitation on the other phones.
